# CB Tuner

A highly accurate, open-source microtonal instrument tuner for Android, built with a modern Jetpack Compose interface and a low-latency C++ audio engine.

## Features
* **Standard & Strobe Tuning:** Toggle between a standard cents-based linear tuner and a highly sensitive phase-tracking strobe visualization.
* **Microtonal & Custom Scala Support:** Includes built-in presets for 12-TET, 24-TET (Quarter-tone), and 31-TET (Huygens-Fokker), plus the ability to import custom `.scl` (Scala) tuning files.
* **Adjustable Base Pitch:** Customise your A4 reference frequency or assign specific frequencies to your Scala root notes.
